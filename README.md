# Samba Verdant 🌱

**[Acesse o projeto online](https://verdant.sambacode.com.br)**

Samba Verdant é um projeto de visualização de dados desenvolvido como parte de uma iniciativa científica. Ele coleta dados diretamente de uma tabela do Google Sheets e os exibe em tempo real por meio de gráficos interativos.

Este projeto está relacionado à iniciativa [Ecology](https://sambacode.com.br/ecology) e foi criado com o objetivo de apoiar pesquisas de iniciação científica na área de ecologia e meio ambiente.

---

## 🔍 Sobre o projeto

Samba Verdant busca facilitar a análise visual de dados coletados durante pesquisas, oferecendo:

- 📊 **Gráficos dinâmicos e intuitivos**
- 🔄 **Integração em tempo real com Google Sheets**

---

## 🚀 Tecnologias utilizadas

- **Next.js** — para o frontend do site
- **Shadcn** — para exibição dos gráficos e estilos

---

## 🧪 Aplicação na pesquisa

Este sistema foi projetado para uma pesquisa de iniciação científica vinculada ao projeto **Ecology**, focado no estudo e monitoramento de dados ambientais. O Samba Verdant serve como ferramenta de apoio à visualização e análise desses dados.

---

## 🛠️ Como rodar localmente

> Certifique-se de ter Node.js e pnpm/yarn instalados.

```bash
git clone https://github.com/Frooszy/verdant.git
cd verdant
npm install
npm run dev
```
